# Advertising Sales Prediction

## Project Overview
This project uses Machine Learning to predict sales based on advertising data.

## Objective
To analyze advertising expenditure and build a model that predicts sales.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow
1. Data loading and exploration
2. Data preprocessing
3. Exploratory data analysis
4. Machine Learning model training
5. Model evaluation

## Project File
- `advertisingLR.ipynb` — Jupyter Notebook containing the project code and analysis.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open `advertisingLR.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.
